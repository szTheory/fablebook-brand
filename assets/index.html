Fablebook assets

Which file to use, version 2.1 (November 11, 2026). Logo files are flat vector art in the exact brand colors with a transparent background: light files are drawn for a light page, dark files for a dark one, and mono files are one-color drawings (Ink or Vellum). There is no shape behind any logo except the rounded tile used for the favicon. The favicon follows the device theme by itself.
